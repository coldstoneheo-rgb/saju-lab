# DESIGN — L2 신살(神殺) 표 조회 (설계만, 코드 0)

- **상태: 초안 → LC 게이트 대상.** 저자 = saju-lab 워커(Claude Opus 5.5), 2026-10-25. 발주 = LC `HO-2026-1025-saju-8b-design-01` 완료 조건 4. 회의 `life-coordinator/docs/meetings/MEETING-2026-1003-saju-lab.md` E2 신살 행 · Q2(목록 N종)를 이 문서가 받는다.
- **순서:** 안A(8b → 격국 → **신살**). 코드 착수는 격국 뒤 별도 HO.
- **반박 가능:** 목록 N종 · 기준 기둥 · 변형 표 채택.

## 0. 요약

신살은 **기준 글자 → 대상 지지(또는 기둥)** 조회표다. 명식 글자만으로 정해지는 결정론 사실이고, 코어는 «어느 기둥에 어떤 신살이 걸렸는가»만 낸다. 길흉 해석·강도·「좋다/나쁘다」는 코어에 없다. 학파 갈림은 ① 목록 선택 ② 기준 기둥(연지/일지) ③ 일부 신살의 변형 표에서 생긴다. 강약·격국처럼 이름 붙은 변형을 **모두 실행해 나란히** 싣고, 기본 변형을 정하지 않는다.

## 1. 입력과 8b · 격국 의존 관계

| 입력 | 원천 |
| --- | --- |
| 네 기둥 천간·지지 | `PillarsResult`(시각 미상이면 시주 없음) |
| 삼합 묶음(寅午戌 · 申子辰 · 巳酉丑 · 亥卯未) | 기존 `docs/rules/INTERACTIONS.md` 삼합 표 재사용 |

```
PillarsResult ──> 신살 sinsal        (8a · 8b · 격국 출력 모두 읽지 않는다)
8a strengthFactors ──> 8b ──> 격국
```

- **신살은 8b 출력에 의존하지 않는다.** 격국에도 의존하지 않는다. 안A 순서는 재료 의존이 아니라 명리 흐름(회의 E2 서문각 안)을 따른 LC 결정이다. 그래서 8b-1 골든 보류나 격국 지연이 신살을 막지 않는다. 필요하면 격국과 병렬 발주할 수 있다(LC 판단).
- 양인(羊刃)은 격국 설계서의 양인 표와 **같은 표를 공유**한다(정의 이중화 금지).

## 2. 목록 N종 — 학파 선택표

| 신살 | 기준 | 대상 | 변형(학파 갈림) | v1 |
| --- | --- | --- | --- | --- |

| 도화 桃花 | 연지·일지의 삼합 | 다른 지지 | 기준 기둥 연지 / 일지 | 寅午戌→卯 · 申子辰→酉 · 巳酉丑→午 · 亥卯未→子, **두 기준 모두 실행** |
| 역마 驛馬 | 같음 | 같음 | 같음 | 寅午戌→申 · 申子辰→寅 · 巳酉丑→亥 · 亥卯未→巳 |

| 백호 白虎 | 기둥(간지 쌍) | 네 기둥 | 甲辰 乙未 丙戌 丁丑 戊辰 壬戌 癸丑 | 단일 표 |

- **N = 7**(회의 Q2 기본값). 대안은 **12신살**(겁살·재살·천살·지살·연살·월살·망신·장성·반안·역마·육해·화개 — 삼합 기준 12자리 순환)이다. 12신살을 넣으면 도화(=연살)·역마·화개가 겹치므로 별도 세트 `sinsal.twelve`로 두고 v1에서는 **제외**한다(사용자 확인 목록).
- 시각 미상: 시지·시주 대상은 계산하지 않고 `precision: "time-unknown"`. 일간·일지 기준은 그대로.
- 자기 자신 매칭: 도화·역마·화개는 기준 지지와 같은 기둥은 대상에서 뺀다(연지 기준이면 연지 제외). 실제로 효력이 있는 것은 **화개뿐**이다 — 화개 대상(戌·辰·丑·未)은 기준 삼합에 속하지만 도화(卯·酉·午·子)·역마(申·寅·亥·巳)의 대상은 기준 삼합 밖이라 기준 지지와 겹칠 수 없다. 교재 갈림이 있으면 착수 HO에서 표에 추가한다.

## 3. 출력 초안

```ts
interface SinsalHit {
  sinsalId: "cheoneul" | "dohwa" | "yeokma" | "hwagae" | "yangin" | "goegang" | "baekho";
  variantId: string;           // 예 "cheoneul.a" · "dohwa.year-basis" · "goegang.day-four"
  basis: { pillar: PillarKey; char: Stem | Branch | `${Stem}-${Branch}` };
  at: PillarKey[];             // 걸린 기둥(연→시)
  doctrine: "unreviewed";
}
// sinsalOf(pillars) → SinsalHit[] — sinsalId → variantId → at 순. 맞는 게 없으면 싣지 않는다.
```

- 길흉·강도·`good`/`bad` 필드 없음. 순서는 표 순서이고 순위가 아니다.
- 어휘: 신살 이름(백호·괴강 등)은 고유명사로만 쓴다. 코어·md·골든에 「흉하다·조심해야」 같은 단정 문장을 쓰지 않는다. 사람 대면 문장은 13단계 + `saju-domain` 스킬.

## 3-1. 공개 계약

`saju-pillars-v1` 기본 응답은 바뀌지 않는다. 신살 블록은 9단계에서 `options.include`(가칭 `sinsal`)로만 열고, 열기 전에는 `INVALID_OPTIONS`(include-only 규칙, `SAJU_PILLARS_API_V1.md`).

## 4. 골든 설계

| 표 | 행 | 셀 | 상태 축 |

| `GOLDEN-SINSAL.md` | 50 × 7종(변형별 열) | `at` 기둥 목록 또는 `-` | `상태` 1축(회의 E2 — 학설 갈림은 목록·변형 선택에서만) |

- 보강: 골든 50에서 각 신살·변형의 적중 0 칸을 실측한 뒤 빈 칸만 보강(괴강 일주 · 백호 · 천을귀인 B 갈림 행).

## 5. 교차 구현

lunar-typescript 1.8.6의 `getDayJiShen`·`getDayXiongSha`(택일 黃曆용 그날의 吉神·凶煞)와 `getDaySha`(그날의 煞方 문자열)·`getTianShen*`(황도·흑도 12신)은 모두 **날짜 단위 택일 정보**다. 명식 기둥 기준 신살과 정의가 달라서 차분 대상이 아니다(`dist/index.d.ts` grep, 2026-10-25 실측). 착수 HO에서 CROSS-IMPL-DIFF §6에 추기한다.
