# 골든 대운표 (검산 완료 · confirmed)

`docs/golden/GOLDEN-PILLARS.md`의 명식 11건에 대해 코어가 산출한 대운(大運)이다. `packages/saju-core/src/l2/golden-daeun.test.ts`가 이 표를 직접 파싱해 코어 산출과 대조한다(열 이름 매핑). 산식 정본은 `docs/rules/DAEUN.md`(7단계 v1: 12절·정규화 KST·3일=1년·소수 그대로·10주·절기표 끝 절단). 세운은 범위 밖.

- **상태 열** `pending` = 코어 산출값, 검산 대기. `confirmed` = 검산 통과, 이후 값이 고정된다(코어가 달라지면 테스트 실패). 16행 전부 2026-09-22 `confirmed`(정정 0) — 대운은 순수 산식이라 페르소나 라운드 없이 LC 독립 재계산(KASI txt 12절 직접 파싱, 1955/1988 정규화) + 리뷰 에이전트 손계산 2건으로 고정. 외부 대조(시중 만세력 3건)는 사용자 표본 대기 → 비고 「교차: …」. `pending` 행도 코어 현재 산출과 같아야 한다 — 코어를 바꾸면 이 표를 다시 생성해야 한다.
- **2026-09-23 `pending` 추가분**(TASK-2026-0923-golden-39): GOLDEN-PILLARS에 새로 들어간 명식 39건의 코어 산출이다(비고 첫 토큰 = 후보 설계표 행 키). 출처에 `TASK-2026-0923-golden-39`가 붙은 pending 행은 이 검산 라운드 동안 pending 상한 20% 계산에서 빠진다. 이 예외는 테스트의 `OPEN_REVIEW_ROUND` 상수 하나로만 열려 있고, 검산을 마치고 confirmed로 올리는 PR에서 그 상수를 지운다.
- **출처 열 빈칸 = 파서 실패**(골든 표 규칙 동일). `pending` 행의 출처는 「코어 산출 <일자>, 검산 대기」.
- **행 = (명식, 순역)**. 성별 `other`(GOLDEN-PILLARS 성별 열)는 순행·역행 두 행. `male`·`female`은 연간 음양 × 성별로 정해진 한 행.
- **열**: `기준 절` = 거리 D를 잰 절(순행 = 출생 뒤 첫 절, 역행 = 출생 이하 마지막 절)과 KST 시각 · `D(분)` = 정수 분 · `startAgeExact` = D ÷ 4320, **소수 4자리로 표기**(코어 값은 그대로, 표기만 반올림) · `시작일` = 출생 + startAgeExact × 365.2425일 · `첫 대운` · `10주` = 순서대로(절기표 끝 2100-12-07을 넘는 주는 잘라서 적고 비고에 표기).
- 출생 시각은 정규화 KST(1955년 두 건은 UTC+8:30 → KST 환산 뒤 입춘 23:18과 1분 차·동시각). 진태양시 미적용. 시각 미상 명식은 골든 11건에 없다(정오 대체는 `l2/daeun.test.ts`로 고정).
- **외부 대조 [ASK]**: 시중 만세력 대운수 대조 3건은 사용자 표본 — 결과가 오면 비고 열에 「교차: …」로.
