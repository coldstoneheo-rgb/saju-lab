# 골든 십신표 (검산 완료 · confirmed)

`docs/golden/GOLDEN-PILLARS.md`의 명식 11건에 대해 코어가 산출한 십신(十神)표다. `packages/saju-core/src/l2/golden-tengods.test.ts`가 이 표를 직접 파싱해 코어 산출과 대조한다(열 이름 매핑).

- **학파 고정** `confirmed` 값은 `yeonhae` 학파 하에서 고정이고, 테스트는 기본 학파(`yeonhae`) 산출과만 대조한다 — `options.hiddenStemSchool: "japyeong"` 호출은 이 표와 대조하지 않으며 코어 회귀가 아니다. `japyeong` 토글 시 값이 바뀌는 장간 셀 20개(실측 2026-09-22): 子 여기 壬 6·卯 여기 甲 7·午 여기 丙 3·酉 여기 庚 2·亥 여기 戊 2 — 전부 유무 변동, 편↔정 변동 0(`japyeong`도 寅·申 여기 戊 채택). `docs/rules/HIDDEN-STEMS.md` 갈림 기록의 戊→己 대안(구현 학파 아님)을 택하면 편↔정이 바뀌는 셀 10개(寅 여기 戊 7·申 여기 戊 3) + 유무 셀 5개(亥 여기 戊 2·午 중기 己 3) = 15개. `japyeong` 골든은 필요 시 별도 표.
- **상태 열** `pending` = 코어 산출값, 역술가 검산 대기(LC가 전통·현대 페르소나 2인 검산 라운드를 돌린 뒤 기입). `confirmed` = 검산 통과, 이후 값이 고정된다(코어가 달라지면 테스트 실패). 11행 전부 2026-09-22 `confirmed`(정정 0). `pending` 행도 코어 현재 산출과 같아야 한다 — 코어를 바꾸면 이 표를 다시 생성해야 한다.
- **2026-09-23 `pending` 추가분**(TASK-2026-0923-golden-39): GOLDEN-PILLARS에 새로 들어간 명식 39건의 코어 산출이다(비고 첫 토큰 = 후보 설계표 행 키). 출처에 `TASK-2026-0923-golden-39`가 붙은 pending 행은 이 검산 라운드 동안 pending 상한 20% 계산에서 빠진다. 이 예외는 테스트의 `OPEN_REVIEW_ROUND` 상수 하나로만 열려 있고, 검산을 마치고 confirmed로 올리는 PR에서 그 상수를 지운다.
- **출처 열 빈칸 = 파서 실패**(골든 표 규칙 동일). `pending` 행의 출처는 「코어 산출 <일자> (<학파>), 검산 대기」.
- 십신 코드: `bigyeon`(비견) `geopjae`(겁재) `siksin`(식신) `sanggwan`(상관) `pyeonjae`(편재) `jeongjae`(정재) `pyeongwan`(편관) `jeonggwan`(정관) `pyeonin`(편인) `jeongin`(정인). 배정 규칙: 일간 기준 같은 오행 = 비견/겁재, 내가 생 = 식신/상관, 내가 극 = 편재/정재, 나를 극 = 편관/정관, 나를 생 = 편인/정인 — 앞이 일간과 같은 음양, 뒤가 다른 음양.
- 열: `연간`·`월간`·`시간` = 그 기둥 천간의 십신(일간 자신은 `-`). `연지정기` 등 = 지지 정기 천간의 십신. `연지장간` 등 = 여기→중기→정기 순 `천간=십신` 나열. 지장간 표는 `docs/rules/HIDDEN-STEMS.md` 기본 학파(`yeonhae`).
