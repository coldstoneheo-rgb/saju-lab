# 골든 합충표 (검산 완료 · confirmed)

`docs/golden/GOLDEN-PILLARS.md`의 명식 50건(2026-09-22 11건 + 09-23 39건)에 대해 코어가 산출한 합충형(合沖刑) 관계 전부다. `packages/saju-core/src/l2/golden-interactions.test.ts`가 이 표를 직접 파싱해 코어 산출과 대조한다(열 이름 매핑). 규칙 정본은 `docs/rules/INTERACTIONS.md`(6단계 v1: 간합·육합·삼합·방합·지지충·형. 파·해·천간충·化 판정·가중은 범위 밖).

- **상태 열** `pending` = 코어 산출값, 역술가 검산 대기(LC가 전통·현대 페르소나 2인 검산 라운드를 돌린 뒤 기입). `confirmed` = 검산 통과, 이후 값이 고정된다(코어가 달라지면 테스트 실패). 11행 전부 2026-09-22 `confirmed`(정정 0). `pending` 행도 코어 현재 산출과 같아야 한다 — 코어를 바꾸면 이 표를 다시 생성해야 한다.
- **2026-09-23 추가분**(TASK-2026-0923-golden-39, 비고 첫 토큰 = 후보 설계표 행 키): GOLDEN-PILLARS에 새로 들어간 명식 39건. 2026-09-23 LC 검산(`life-coordinator/docs/VERIFY-2026-0923-golden-l2-39.md`, 규칙 md·KASI·tzdb만으로 독립 재계산, 불일치 0)으로 `confirmed`. 이 표에 pending 행은 없다.
- **출처 열 빈칸 = 파서 실패**(골든 표 규칙 동일). `pending` 행의 출처는 「코어 산출 <일자>, 검산 대기」.
- **셀 형식** `글자-글자:기둥-기둥`, 관계가 여럿이면 공백 구분, 없으면 `-`. 글자·기둥은 명식 순서(연→월→일→시). 기둥은 `year month day time`. 3자 관계(삼합·방합 완전, 삼형 완전)는 글자 3개·기둥 3개, 2자는 2개(삼합 2자 = 반합, 삼형 2자 = 부분 형). `adjacent`·`shared`·`complete`는 기둥 수와 위치에서 유도되므로 셀에 적지 않는다.
- **글자 순서는 명식 순서(연→월→일→시)**. `jeong-im:month-day`(g-2000)와 `im-jeong:month-day`(g-1988)는 오탈자가 아니라 이 규칙의 결과다(같은 丁壬 합, 기둥 위치가 다름). `adjacent`·`shared`·`complete`는 응답 필드가 정본이며 비고에 적지 않는다.
- **명식 열**은 대조 편의용(`천간-지지` 기둥 순). 파서는 `GOLDEN-PILLARS.md` 입력으로 코어를 다시 돌려 이 열과 관계 열을 함께 대조한다.
- 관계 0 명식: confirmed 11건에는 없다(전부 1건 이상). 2026-09-23 추가분 중 3건(`g-1946-05-19-2359` · `g-1963-06-06-1000` · `g-2022-01-25-0350`)이 관계 0이다(巳巳·丑丑·寅寅은 자형 아님. 천간은 간합이 없고, 丙壬은 천간충이지만 천간충(甲庚·乙辛·丙壬·丁癸, `docs/rules/INTERACTIONS.md` 표 5 각주)은 v1 밖이다. 甲戊는 천간충이 아니다). 합성 관계 0 케이스는 `l2/interactions.test.ts`에 그대로 있다.
